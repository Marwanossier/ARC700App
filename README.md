## 🛠️ Development & Deployment

### Local Development Setup
```bash
# Install dependencies (300s timeout recommended)
cd /home/user/webapp && npm install

# Build the project
npm run build

# Start with PM2 (for persistent service)
pm2 start ecosystem.config.cjs

# Test the website
curl http://localhost:3000

# View logs (non-blocking)
pm2 logs --nostream
```

### Production Deployment to Cloudflare Pages
```bash
# Setup Cloudflare API (required first step)
setup_cloudflare_api_key

# Build for production
npm run build

# Deploy to Cloudflare Pages
npx wrangler pages deploy dist --project-name apex-reportcraft

# Configure custom domain (optional)
npx wrangler pages domain add your-domain.com --project-name apex-reportcraft
```

### SEO Configuration
- **Google Analytics ID**: Update `GA_MEASUREMENT_ID` in all HTML files
- **Social Media Images**: Add og-image.jpg and twitter-card.jpg to public/
- **Sitemap**: Generate and submit to search engines
- **Search Console**: Verify domain ownership
