# ARC (APEX ReportCraft) - Marketing Website

## 🚀 Overview

Professional, enterprise-grade marketing website for ARC (APEX ReportCraft) - the leading Oracle APEX reporting solution with native integration, AI-powered features, and Arabic RTL support.

## ✨ Features

### Homepage Components
- **Hero Section**: Compelling value proposition with clear CTAs
- **Trust Bar**: Social proof (850K+ APEX developers worldwide)
- **Features Showcase**: 6 key differentiators with icons
- **Pricing Section**: 4 transparent pricing tiers
- **CTA Section**: Strong conversion-focused call-to-action
- **Professional Footer**: Comprehensive navigation and links

### Key Marketing Messages

#### Value Proposition
**"APEX Reporting Made Simple"**

Transform your data into actionable insights with enterprise-grade reporting built on Oracle APEX.

#### Core Differentiators
1. **Native APEX Integration** - Pure APEX plug-in, no external servers
2. **AI-Powered Assistant** - Natural language queries and smart insights
3. **Arabic RTL Support** - First APEX reporting tool for GCC market
4. **Real-Time Dashboards** - Live data with auto-refresh
5. **Multi-Format Export** - PDF, Excel, Word, CSV, JSON, and more
6. **Enterprise Security** - SOC 2, GDPR, ISO 27001 compliant

## 🛠️ Technical Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite 6.3.5
- **Styling**: Custom CSS with modern gradients
- **Icons**: Font Awesome 6.4.0
- **Fonts**: Inter (Google Fonts)
- **Router**: React Router DOM 7.9.4
- **Animations**: Framer Motion 12.23.24

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
